Apple
Public beta through Apple

Install with TestFlight

TestFlight is Apple’s official beta-testing app. You do not need to send us your Apple Account email when joining with the public link.

  1. 1
    Open the Bedford invitation

    Tap the button below on the iPhone or iPad where you want Bedford Road Theatre.

    Open the TestFlight invitation
  2. 2
    Install TestFlight if Apple asks

    Tap View in App Store, install the free TestFlight app, then return to this page or reopen the invitation link.

  3. 3
    Accept the invitation

    In TestFlight, tap Accept and then Install beside Bedford Road Theatre.

  4. 4
    Open Bedford and sign in

    Use the same Bedford Road username and password you use on the website. Allow notifications when asked so Community messages can reach you.

Keeping iOS updated

Open TestFlight, choose Bedford Road Theatre, and turn on Automatic Updates. TestFlight builds are available for up to 90 days, so install a newer build when TestFlight alerts you.

Android
Direct Bedford download

Install the Android APK

Because this testing version is delivered directly instead of through Google Play, Android may call it an unknown app or unfamiliar file. Read the filename and source before proceeding.

Only continue for this exact downloadBedfordRoadMusical-2.15.6.apk from the Bedford Road Theatre website. Never use these steps for an APK sent through a random message, email, advertisement, or different website.
  1. 1
    Download the Bedford APK

    Tap below. If Chrome says the file may be harmful because APK files can install software, confirm the filename and Bedford website, then choose Download anyway.

    Download Android 2.15.6About 86 MB · Android phone and tablet
  2. 2
    Open the finished download

    Tap Open in the download message. If it disappeared, open Chrome’s menu → Downloads, or open the device’s Files/My Files app → Downloads.

  3. 3
    Allow this one installation source

    If Android says your browser or Files app is not allowed to install unknown apps, tap Settings, enable Allow from this source for the app shown, then press Back. This permission belongs to that browser or file manager—not to Bedford.

  4. 4
    Review and install

    Confirm the app name is Bedford Road Musical, then tap Install. If Play Protect offers to scan the app, let it scan. For an “unknown developer” or unfamiliar-app prompt, expand More details and choose Install anyway only after confirming this page and filename.

  5. 5
    Open Bedford and sign in

    Tap Open, sign in with your Bedford account, and allow notifications. You can turn off “Allow from this source” afterward in Android Settings.

Samsung says Auto Blocker stopped the installation

School-managed devices or Samsung security settings may prevent direct APK installation. Do not remove school management or broadly disable device protection. Use the Bedford web portal on that device and ask the production administrator for help.

The Install button does not appear

Open Settings and search for Install unknown apps. Select the browser or Files app that opened this Bedford APK, allow that source temporarily, and reopen the downloaded file.

Android says the app is harmful—not merely unknown

Stop and contact the production administrator. Do not bypass a malware finding. The ordinary testing-build prompts usually describe an unknown source, unfamiliar app, or potential risk rather than reporting detected malware.

Keeping Android updated

Return to this page when the app announces an update. Download the newer Bedford APK and install it over the existing app—do not uninstall first, because uninstalling can remove device-only downloads.
